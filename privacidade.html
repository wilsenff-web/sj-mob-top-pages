Política de Privacidade — SJ MOB TOP

Versão inicial para revisão do responsável — 01/11/2026.

Dados tratados

O sistema registra dados de motoristas (incluindo nome, telefone e informações da CNH), veículos, viagens, lançamentos financeiros, pendências, manutenção e metas, além de dados de autenticação do administrador.

Finalidades e armazenamento

Os registros são utilizados para gestão operacional da frota, controle financeiro e cópias de segurança. Os dados operacionais ficam no Supabase.

Google Drive

Com autorização do administrador, o aplicativo usa o escopo Google Drive drive.file para criar e gerenciar arquivos próprios de backup. Um token de atualização criptografado fica armazenado no servidor para permitir novos envios. Os arquivos JSON enviados podem conter dados pessoais e financeiros dos registros da frota. O backup não inclui automaticamente os arquivos binários anexados.

Os arquivos são armazenados na conta Google Drive autorizada e não são usados para publicidade nem vendidos. A autorização pode ser revogada nas configurações da Conta Google. A revogação não exclui arquivos já enviados.

Compartilhamento, retenção e direitos

Os dados são processados por provedores necessários ao serviço, como Supabase e Google Drive, quando autorizado. Os backups permanecem no Drive até exclusão pelo titular; não há política automática de retenção implementada.
