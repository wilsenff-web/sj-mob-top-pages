1. Conectar seu Supabase

Informe somente a URL do projeto e a chave pública publishable (ou anon). Nunca use service_role, secret key ou senha do banco.

Configuração salva apenas neste navegador. Para abrir em outro dispositivo, informe novamente URL e chave pública.

2. Entrar no sistema

Acesse com o usuário criado no Supabase Authentication.

Crie seu usuário em Authentication → Users no Supabase. Este sistema não oferece cadastro público.
